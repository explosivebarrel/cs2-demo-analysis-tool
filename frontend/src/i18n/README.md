# i18n — словари интерфейса

Интерфейс использует **i18next**. Словари — вложенные JSON по доменам:

```
locales/
  ru/  common.json  demos.json  match.json  player.json
       metrics.json replay.json heatmaps.json chat.json about.json
  en/  ... (зеркально)
```

- `common` — навигация, кнопки, статусы, базовые подписи статистики
- остальные — тексты соответствующих страниц (namespace совпадает с доменом)

## Как это работает

- Компоненты вызывают глобальный `t(key)` из `src/i18n.ts` (фасад над i18next).
- `defaultNS` — `common`; незнакомый ключ ищется во всех namespace (`fallbackNS`),
  поэтому старые плоские ключи (`t('layerKills')`) работают без префикса.
- Новые ключи preferable с явным namespace: `t('metrics:reaction.title')`.
- Перерисовка при смене языка — через `useLang()` из `App.tsx`: компонент обязан
  его вызвать (хотя бы для эффекта), иначе не перерисуется.

## Как добавить новый язык (например, de)

1. Скопируй папку: `locales/en/` → `locales/de/`, переведи значения
   (набор ключей менять нельзя — RU/EN/DE должны совпадать).
2. В `src/i18n.ts` добавь блок `de: { ... }` в `resources` и
   `'de'` в тип `Lang`.
3. Готово — переключатель в навбаре подхватит язык через `setLang`.

## Как добавить новые тексты

1. Ключ — в оба файла (ru + en) своего домена; наборы ключей должны совпадать.
2. Подстановки — интерполяция i18next: JSON `"Норма {{value}} мс"`,
   вызов `t('metrics:reaction.norm', { value })`.
